# jallomoth.github.io

Personal website for Jallomoth — live at [jallomoth.github.io](https://jallomoth.github.io).

The site is a React single-page application deployed to GitHub Pages. All source code lives in `my-site/`.

## Quick start

```bash
cd my-site
npm install
npm run dev
```

See [my-site/README.md](my-site/README.md) for full documentation.
